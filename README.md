# Task Management App
A dynamic web application built with HTML, CSS, and JavaScript that allows users to create tasks with deadlines, assign categories, filter tasks by status or category, automatically mark overdue tasks, and persist data using browser Local Storage.
#Project Reflection
## .1. Challenges faced during the project
The main challenge I faced during this project was researching the available built-in methods for each JavaScript functionality, since we did not cover many of those specific methods during class. Figuring out which array, string, date, and DOM methods to use to filter tasks, check overdue dates, and save data required extra effort.
## .2. How I approached solving those challenges
I approached and solved these challenges by actively researching and reading official documentation (such as MDN Web Docs and W3Schools). Whenever I needed to perform a specific action, I looked up the appropriate method in the documentation, tested how it worked in small pieces, and then integrated it into my application.
## .3. What I would improve if given more time
If given more time, I would focus on deepening my understanding of every parameter that each JavaScript method accepts. Understanding all optional and required parameters in greater detail would help me write cleaner, more flexible logic and solve future problems faster without having to look up basic syntax.
